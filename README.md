# Nova Poshta UI Tests 

Проєкт автоматизованого UI-тестування веб-застосунку "Нова Пошта" (novaposhta.ua), розроблений з використанням патерну **Page Object Model (POM)**.

## Архітектура проєкту

```text
nova_poshta_tests/
├── .github/workflows/
│   └── main.yml              # CI/CD пайплайн для автоматичного запуску
├── pages/                    # Класи Page Object Model
│   ├── base_page.py          # Базовий клас (wait, safe_click з обробкою StaleElement)
│   ├── branches_page.py      # Сторінка відділень (з fallback-логікою навігації)
│   ├── home_page.py          # Головна сторінка (пошук ЕН та меню)
│   └── tracking_page.py      # Сторінка результатів трекінгу
├── tests/                    # Логіка тестів
│   ├── conftest.py           # Налаштування WebDriver (headless mode)
│   ├── test_branches.py      # Сценарії пошуку відділень
│   └── test_tracking.py      # Сценарії відстеження посилок
├── requirements.txt          # Залежності проєкту
└── README.md                 # Опис проєкту
```

## Короткий опис реалізованих тестових сценаріїв
В рамках проєкту автоматизовано перевірку ключового функціоналу сайту. Тести написані з урахуванням можливих змін у DOM-дереві.

1. Модуль відстеження посилок (test_tracking.py)
Пошук за валідним номером ЕН: Введення існуючого номеру накладної та перевірка коректного зчитування статусу посилки (напр., "Отримана", "Прямує").
- Пошук за невалідним номером ЕН: Введення завідомо неправильного номеру (напр., 14 нулів) та валідація появи повідомлення "Не знайдено...".

- Обробка порожнього поля: Спроба ініціювати пошук без введення даних. Перевірка того, що система не виконує submit та не переходить на сторінку помилки (early return).

2. Модуль пошуку відділень (test_branches.py)
- Пошук існуючого відділення: Навігація до розділу відділень (через меню або fallback URL), вибір міста з випадаючого списку (напр., "Київ") та пошук відділення "1". Перевірка, що лічильник результатів показує > 0.

- Пошук неіснуючого відділення: Вибір міста та введення вигаданого номеру відділення (напр., "99999"). Перевірка, що результатів 0 і відображається коректне повідомлення про відсутність відділень.

## Локальний запуск тестів
Клонуйте репозиторій:

```Bash
git clone <посилання_на_ваш_репозиторій>
cd nova_poshta_tests
```
Створіть та активуйте віртуальне середовище:

```Bash
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
venv\Scripts\activate     # Для Windows
```
Встановіть залежності:

```Bash
pip install -r requirements.txt
```
Запустіть тести з генерацією локального HTML-звіту:

```Bash
pytest tests/ --html=report.html --self-contained-html
```
